# 08 — Feedback Engine

## Overview

The feedback engine (`js/feedback.js`) converts the raw numerical output of `analyzer.js` into human-readable feedback text. It is a pure logic module — it does not access the DOM and does not call any external service.

## The Module

```js
const feedbackEngine = {
    generateFeedback(analysis, question) { ... },
    getReadinessLevel(score) { ... }
};
```

---

## `generateFeedback(analysis, question)`

Takes the result object from `analyzer.analyzeAnswer()` and returns:

```js
{
    strengths: String[],    // up to 3 items
    missing: String[],      // up to 3 items
    suggestions: String[]   // exactly 1 item
}
```

### Empty Answer Handling

If `analysis.isEmpty === true` or `analysis.wordCount === 0`:

```js
return {
    strengths: ["None (No answer was submitted)."],
    missing: question.concepts.map(c => c.name),  // all concepts listed as missing
    suggestions: ["Provide a complete response addressing the key concepts in the question."]
};
```

An empty answer receives no false strengths. All concepts are listed as missing.

---

### Strengths Logic

Strengths are generated by checking component scores against thresholds:

| Condition | Strength Message |
|---|---|
| `conceptScore >= 70` | "Excellent coverage of the core concepts." |
| `matchedConcepts.length > 0` (fallback) | "Successfully identified: [concept names]." |
| `qualityScore >= 80` | "Appropriate level of detail and answer length." |
| `structureScore >= 75` AND `question.structure.length > 0` | "Clear and well-structured answer progression." |
| `communicationScore >= 90` AND `wordCount >= 10` | "Professional communication with no filler words." |

If no strength conditions are met: `"Attempted to address the question."`

Output is capped at 3 strengths (`.slice(0, 3)`).

---

### Missing Concepts Logic

```js
if (analysis.missingConcepts.length > 0) {
    missing = [...analysis.missingConcepts];
} else {
    missing.push("No major expected concepts were missing.");
}
```

Missing concept names come directly from `analysis.missingConcepts`, which is populated by `analyzer.matchConcepts()`. Output is capped at 3 items.

---

### Suggestion Logic (Priority-Based)

Exactly one suggestion is generated, based on the weakest scoring dimension:

| Priority | Condition | Suggestion |
|---|---|---|
| 1st | `conceptScore < 50` | Focus on missing concepts (names the first missing concept) |
| 2nd | `qualityScore < 50` | Provide more complete response (states ideal word range) |
| 3rd | `structureScore < 50` AND question has structure | Organize answer with clearer structure element |
| 4th | `communicationScore < 70` | Reduce filler words and avoid repeating phrases |
| Default | All scores acceptable | "Great answer! Maintain this level of detail and clarity." |

---

## `getReadinessLevel(score)` — Readiness Thresholds

Called in `ui.renderResults()` with the final session average score:

```js
getReadinessLevel(score) {
    if (score >= 90) return "Interview Ready";
    if (score >= 75) return "Nearly Ready";
    if (score >= 60) return "Needs Practice";
    return "More Preparation Needed";
}
```

| Score Range | Level |
|---|---|
| 90–100 | Interview Ready |
| 75–89 | Nearly Ready |
| 60–74 | Needs Practice |
| 0–59 | More Preparation Needed |

This label is displayed below the score ring on the Results screen.

---

## Question-Level vs Session-Level Feedback

### Question-Level Feedback (per question, shown immediately after submission)

- Generated by `feedbackEngine.generateFeedback(analysis, question)`
- Shows: score (0–100), strengths (up to 3), missing concepts (up to 3), one improvement suggestion
- Also shows "Why this score?" breakdown: Concept %, Quality %, Structure %, Communication %
- Displayed in the feedback card within the Interview screen

### Session-Level Feedback (final results, shown once at the end)

Computed inside `ui.renderResults(resultsArray, questionsArray)`:

- **Overall score** = `Math.round(sum of 5 totalScore values / 5)`
- **Category averages** = average of each component score across all 5 questions
- **Strengths** — category-level thresholds:
  - `avgConcept >= 70` → "Strong concept coverage across the session."
  - `avgQuality >= 75` → "Appropriate answer completeness throughout."
  - `avgStructure >= 75` → "Clear and logical structure in most answers."
  - `avgComm >= 80` → "Good professional communication style."
- **Improvements** — sorted by lowest average category score; 1–2 shown depending on final score
- **Question Review** — Q1–Q5 cards showing question text, score, and key strength or missing concept
- **Readiness level** — `feedbackEngine.getReadinessLevel(finalScore)` applied to the session average

## Data Flow: Where Feedback Is Consumed

```
analyzer.analyzeAnswer(answer, question)
    |
    v  (analysis object)
feedbackEngine.generateFeedback(analysis, question)
    |
    v  (feedbackStrs: { strengths[], missing[], suggestions[] })
ui.showFeedback(analysis, feedbackStrs, isLast)
    |
    v  (per-question feedback card rendered in DOM)

--- after Q5 ---

ui.renderResults(state.results, state.questions)
    |
    v  (uses feedbackEngine.getReadinessLevel for readiness label)
    |
    v  (builds session-level strengths/improvements from average scores)
Results screen displayed
```
